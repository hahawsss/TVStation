# TVStation 安装说明（Docker 版）

> 飞牛 fnOS 用户：**最省事的是直接装应用中心里的原生版**（发布包里的 `.fpk`），不用 Docker、不用配内存盘。
> 下面是 Docker 版的安装方法。

发布包里有三样东西会用到：

| 文件 | 用途 |
|---|---|
| `tvstation-<版本号>-compiled-amd64.tar.gz` | Docker 镜像包 |
| `docker-compose.yml` | 容器配置（已经写好内存盘，一般只需要改片库路径） |
| `安装说明.md` | 就是这份 |

## 先说一件最重要的事：内存盘

TVStation 播出时，每个频道每隔几秒就写一个切片，一刻不停。这些切片**必须放在内存盘上**，
否则固态硬盘会被写坏、机械硬盘会拖慢播出。

`docker-compose.yml` 里已经写好了（`tmpfs` 那一段），**只要按下面的步骤用这个文件建容器，就不用管它**。

要注意的只有一点：**很多 NAS 的「容器」管理界面不认内存盘这一项**。在那个界面里编辑、重建容器，
内存盘会悄悄丢掉。所以：

- 配置、升级都在 **Compose 项目 / 项目 / 应用程序 / Stack** 里改，不要在「容器」列表里点编辑；
- 万一丢了，软件每个页面顶部会出现红色提示「播出切片没在内存盘上」，点「打开修复向导」，按你的平台照做即可。

内存盘大小按频道数给：**一路约 200MB，10 路给 2g**。改 `docker-compose.yml` 里 `size=2g` 那个数字。

## 飞牛 fnOS

1. 打开「Docker」→「本地镜像」→ 导入 `tvstation-<版本号>-compiled-amd64.tar.gz`。
2. 在「我的文件」里新建一个文件夹（比如 `tvstation`），把 `docker-compose.yml` 放进去。
3. 用文本编辑器打开这个 `docker-compose.yml`，把 ② 片库那一行左边改成你的片库路径（飞牛第一块存储空间是 `/vol1`）。
4. 「Docker」→「Compose」→「新增项目」：
   - 项目名称：`tvstation`（**只能用小写字母、数字、`-` 和 `_`，不能有点号**，所以不能写 `tvstation-2.2.24`，可以写 `tvstation-2-2-24`）
   - 路径：选第 2 步那个文件夹，提示「已包含 docker-compose 配置文件」时点「确认」
   - 勾上「创建项目后立即启动」→ 确认
5. 浏览器打开 `http://NAS地址:8890`。

## 群晖 Synology（DSM 7.2 以上，Container Manager）

1. 「Container Manager」→「映像」→「导入」→ 选 `tvstation-<版本号>-compiled-amd64.tar.gz`。
2. 在 File Station 里新建文件夹（比如 `docker/tvstation`），把 `docker-compose.yml` 放进去，
   把 ② 片库那一行左边改成你的路径（群晖一般是 `/volume1/...`）。
3. 「Container Manager」→「项目」→「新增」：项目名称 `tvstation`，路径选第 2 步的文件夹，
   来源选「使用现有的 docker-compose.yml」→ 下一步 → 完成。
4. 浏览器打开 `http://NAS地址:8890`。

> 不想用项目的话：也可以用普通方式建容器，然后在容器「编辑」里勾选**「使用高权限执行容器」**。
> 容器有高权限时，软件启动会自己挂内存盘。代价是容器权限变大。

## 威联通 QNAP（Container Station 3）

1. 用 SSH 执行 `docker load -i tvstation-<版本号>-compiled-amd64.tar.gz`（或在 Container Station「映像」里导入）。
2. 「Container Station」→「应用程序」→「创建」：名称 `tvstation`，把 `docker-compose.yml` 的内容粘进去，
   改好 ② 片库路径（威联通一般是 `/share/...`），`./data` 改成一个绝对路径（比如 `/share/Container/tvstation/data`）→ 创建。
3. 浏览器打开 `http://NAS地址:8890`。

> 也可以普通方式建容器后，在高级设置里打开**「特权模式」**，软件启动会自己挂内存盘。

## Unraid

1. 用终端执行 `docker load -i tvstation-<版本号>-compiled-amd64.tar.gz`。
2. 「Docker」→「Add Container」，切到右上角 **Advanced View**：
   - Repository：`tvstation:<版本号>`
   - Network：Bridge，端口 `8890` → `8890`
   - 路径：`/mnt/user/appdata/tvstation` → `/data`；你的片库 → `/media`（只读）
   - Variables：`PORT=8890`、`APP_PORT=8890`
   - Post Arguments 留空；**Extra Parameters** 填：
     `--tmpfs /data/hls:size=2g,mode=1777`
3. Apply。浏览器打开 `http://NAS地址:8890`。

## Portainer

1. 「Images」→「Import」上传 `tvstation-<版本号>-compiled-amd64.tar.gz`。
2. 「Stacks」→「Add stack」：名称 `tvstation`，把 `docker-compose.yml` 的内容粘进 Web editor，
   改好 ② 片库路径，`./data` 改成绝对路径 →「Deploy the stack」。

## 命令行

```bash
docker load -i tvstation-<版本号>-compiled-amd64.tar.gz
mkdir -p ~/tvstation && cd ~/tvstation
# 把 docker-compose.yml 放到这里，改好 ② 片库路径
docker compose up -d
```

不用 compose 的话，`docker run` 必须带上 `--tmpfs`：

```bash
docker run -d --name tvstation --restart unless-stopped \
  -p 8890:8890 \
  -v /你的数据文件夹:/data \
  -v /你的片库:/media:ro \
  -v /etc/localtime:/etc/localtime:ro \
  -v /etc/machine-id:/host/etc/machine-id:ro \
  --tmpfs /data/hls:size=2g,mode=1777 \
  -e PORT=8890 -e APP_PORT=8890 \
  tvstation:<版本号>
```

## 升级

1. 导入新版本的镜像包。
2. 把**原来项目里**的 `docker-compose.yml` 换成新版本的（或者只把 `image:` 和 `container_name:` 里的版本号改成新的；
   片库路径记得保持你原来改过的）。
3. 在**同一个** Compose 项目 / 项目 / 应用程序 / Stack 里重新构建（命令行：`docker compose up -d`）。

频道、媒体库、授权都在数据文件夹（`./data`）里，升级不受影响。

★ **不要为新版本另建一个项目文件夹**：`./data` 跟着项目文件夹走，新文件夹里是空的，看起来就像数据全没了。

## 常见问题

**页面顶部一直显示「播出切片没在内存盘上」**
点「打开修复向导」，按你的平台照做。改完、容器重新启动后点「重新检查」。

**想把内存盘调大或调小**
内存盘大小是上限，不是占用：写多少占多少内存，一路频道一般 100~200 MB。
改 `docker-compose.yml` 里 `tmpfs` 那一行的 `size=2g`（比如改成 `size=4g`），在**同一个** Compose 项目 / 项目 / 应用程序 / Stack 里重新构建；
用 `docker run` 或 Unraid 的，改 `--tmpfs` 里的 `size=` 再重建容器。建议不超过本机内存的一半。
容器开了特权模式的话，也可以直接在网页「系统设置 → 内存盘」里调，不用改配置。

**时间不对（定期扫描、节目表差了几个小时）**
软件默认跟随 NAS 的时区。没挂 `/etc/localtime` 的容器（比如 Unraid 模板）会按北京时间跑。
打开网页「系统设置 → 系统信息 → 时区」选你所在的时区，立即生效，不用重建容器。

**端口 8890 被占用**
把 `docker-compose.yml` 里 `8890:8890` 和 `PORT` / `APP_PORT` 三处都改成别的端口。

**容器起不来，报 `/dev/dri`**
说明打开了核显那两行但主机没有核显，把它们重新注释掉。
